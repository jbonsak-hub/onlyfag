# Enkeltstående undervisningsmoduler

Brukerens faste ønske: Små sider med én interaktiv oppgave skal passe i nettleservinduet uten scrolling. Grafen eller illustrasjonen skal prioriteres, bruke tilgjengelig høyde og ha tydelige linjer, punkter og lesbar tekst for elever bakerst i rommet. Legg kompakte uttrykk og valg ved siden av grafen på store skjermer. Unngå overlapp mellom etiketter når innhold flyttes eller vinduet endrer størrelse.

Derivertmodulen ligger i `matte/derivert/index.html` og har ingen inngående menylenke. A og B flyttes manuelt og uavhengig; det finnes ingen egen Δx-knapp eller animasjon. Grafvinduet starter ved x = −1,5. Navn og koordinatuttrykk står fast i menyen til høyre, uten flytende tekstetiketter på linjer og trekant. Bare punktnavnene A og B følger punktene.
