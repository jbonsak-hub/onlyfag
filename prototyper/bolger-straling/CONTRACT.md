# Module contract

Layout refinement: keep separate teaching models separate. Only transverse/longitudinal share their original two-option selector; sound and water are independently expandable examples, and standing waves/resonance have their own figures. Root `arrangeModels` moves existing diagram nodes and controls into `.model-visual`, `.model-panel` and `.model-footer` after mount; preserve IDs and do not assume controls remain direct children. On desktop, drawings keep their natural aspect ratio and readable height, with controls on the right. Do not shrink every SVG with a low global height cap.

Each content file is an ES module exporting `topics`, an array of topic objects. Only edit the file assigned to you.

Topic: `{id, title, kicker, summary, sections:[{title,body}], terms:[{term,definition}], questions:[...], resources:[{label,url}], mount(root,api)}`.

Section body is trusted HTML. Include diagram/widget HTML inside section bodies. Root has styles for `.concept-grid`, `.concept`, `.key`, `.model`, `.controls`, `.control`, `.readout`, `.model-note`, `.legend`, `.table-wrap`, `.compare-table`, `.steps`, `.mini-label`, `.wide`. You may include a single scoped `<style>` in the first section. Prefix all DOM IDs and selectors by your module file prefix. Use semantic labels and accessible SVG titles/descriptions. SVG viewBox typically `0 0 760 300`; widths responsive 100%. Tables need `.table-wrap`.

Questions: `{id,type:'mcq'|'number'|'open',prompt,choices:[strings],correct:0,answer:'explanation HTML',value:123,tolerance:0.1,unit:'m',hint:'...',level:'Start'|'Bruk'|'Utfordring'}`. mcq uses correct index; number uses value/tolerance; open uses answer. IDs globally unique. Put all necessary context/figures in prompt; do not refer to invisible original attachments. At least 10 varied questions per topic. Answers may use HTML and Unicode/sup/sub for equations. Do not require LaTeX library.

`mount(root,api)` optional. `api.onFrame(fn, target)` registers an animation callback with local elapsed seconds; target is a selector or node inside its `.model`. Separate models must register separate callbacks and clocks. Root generates one compact pause/resume button per animated model. Use `api.now(target)` for event timestamps and `api.repaint(target)` to redraw at the frozen/current local time; unqualified repaint redraws all models. Static figures render directly on input and do not register an animation clock. Root owns clocks, reduced motion, inactive dialog/details handling and cleanup; do not add duplicate pause or speed UI, RAF loops, timers or wall-clock timestamps. Event listeners on module elements can be normal; root removed on navigation. Return optional cleanup. No network dependencies or third-party JS. Animations accurately modeled or explicitly labeled as schematic. Controls must alter the actual displayed model. Provide useful initial static state.

Use nb language, concise explanations suitable Naturfag Vg1. No 'Modul 1' labels. Kicker may be empty; avoid redundant subtitle lines. Avoid old source mistakes. Resources may be links; no iframes needed. Preserve separation of Fagstoff/Oppgavebank in root. No placeholder content.


Current visual conventions (15 November 2026): definitions are vertical lists, calculations use stacked fractions and aligned equals, worked examples use balanced columns when space permits, and sections have clear breathing room. A custom figure layout may opt out of generic reparenting with `data-model-layout="custom"`; a direct `data-model-full-width` child spans the complete model header. EM spectrum uses the full model width; RGB remains a compact, complete figure. Optical refractive indices are internal calculations only, never pupil-facing notation. Quantum energy-level n remains valid.


16 November 2026: pause controls overlay the drawing inside `.animation-surface`; do not add a separate toolbar row. Reserve the upper-right 38×36 pixels of each drawing for the pause button. Atomic energies and editable levels use aJ (1 aJ = 10⁻¹⁸ J), photon readouts in the EM overview use J; no pupil-facing electronvolt units. Hydrogen energies stay fixed while level selectors move; only the custom model permits changing the energy values. The waves topic composes independent helpers for flight Doppler/audio, refraction, practical refraction examples, diffraction and resonance. Audio is opt-in, off by default, and must stop on pause, hidden tab and teardown. Spectral element data must stay tied to actual sources, with neutral/ion stages and missing data explicit.
